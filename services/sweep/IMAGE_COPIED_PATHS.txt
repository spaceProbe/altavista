# from, and a docker-gated test refuses when a commit touching these paths has landed since).
#
# ONE list, read by services/sweep/build-image.sh (to record whether the tree was dirty under
# these paths at build time) and by crates/av-sweep/tests/k8s_sweep.rs (to run
# `git log <recorded_commit>..HEAD -- <these paths>`) -- never duplicated between the two.
#
# Chosen, not guessed: `crates/av-sweep` itself, its committed `proto/altavista/v1` input
# (crates/av-cdm/build.rs compiles it), and the transitive closure of av-sweep's own LOCAL
# (within-this-repository) `normal`+`build` dependencies in the image's feature state --
# `cargo tree -p av-sweep --no-default-features -e normal,build --prefix none --locked`, filtered
# to path dependencies (log: rounds/heavy-ct/scratch/t2b/logs/cargo-tree-nodefault.log). That is
# the same set with GMAT out: `gmat-sys` is not in it (`cargo tree -p av-sweep --no-default-features
# -i gmat-sys` finds nothing). Dev-only edges are filtered out, as for services/tiles/.
